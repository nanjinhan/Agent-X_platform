# SIGNALS 구현 태스크 (T1~T30)

> 순서 근거: SRS 22.4 리스크 완화 순서 (시장데이터 → 성과 계산 → 해시체인 최우선) + Phase 경계.
> 상태 표기: ⬜ 대기 / 🔄 진행 중 / ✅ 완료

## Phase 0 — 법적 기반 (개발과 병행, 코드 아님)

법인 설립, 유사투자자문업 신고, 법률의견서(REG-001~003), PG·시장데이터 계약.
**어느 시점에도 이게 안 끝나면 서비스 오픈 불가.**

## 크리티컬 패스 메모

1. **T2→T9→T12**: 시장데이터 없으면 성과 계산 없음. T12 골든 테스트(오차 0.01%p)가 Phase 1의 실질 관문.
2. **T15는 완료가 아니라 시작**: 자체 에이전트 30일 페이퍼 트레이딩이 그때부터 흐름. T15 지연 = M3 지연.
3. **T6은 비가역**: 해시 입력 필드·서명 방식은 이후 변경 시 과거 체인 재구성 불가.
